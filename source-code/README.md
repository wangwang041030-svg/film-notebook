# 电影品鉴官

简洁的个人电影收藏与观影手记网站。

## 已有功能

- 电影网格、类型筛选、片名／导演／影评搜索、年份与评分排序。
- 收藏／想看／已看，评分、观看日期、影评编辑。
- 多资源链接、提取码、清晰度与录屏时间点。
- JSON 导入与同名同年电影合并，保留已有影评。
- JSON 备份与 Markdown 影评导出。
- 自带 API Key，调用 DeepSeek、OpenAI 或硅基流动整理影评；密钥不存储。
- 无 API Key 时可复制整理指令到 AI 网页。
- 整理结果单独保存，原始影评保留。

## 数据与当前状态

个人片单、影评和整理结果保存在当前浏览器 localStorage，并未跨设备同步。清理浏览器数据前应导出备份，换设备后导入恢复。其他访客看不到你的本地笔记。

十部示例电影没有真实资源，也不代表你的观影记录。真实资源需要由录屏提取或手动添加。网站不扫描电脑或自动识别上传视频。

代码与四项自动化检查已完成；当前运行环境禁止本地监听端口，未完成浏览器视觉检查。发布时无法解析 git.chatgpt-team.site，源码未成功推送，站点尚未发布。已注册站点身份保留在 .openai/hosting.json；恢复发布时请复用该身份，不要重复创建站点。

## 开发

需要 Node.js 20+，无第三方依赖。

```sh
npm run build
npm test
node scripts/preview.mjs
```

开发预览地址：http://localhost:4173

`film-notebook.html` 是可直接打开的独立预览；通过文件打开时没有服务端 AI 接口，可使用“复制指令”功能。

服务端入口：dist/server/index.js，标准 Cloudflare Worker ES module。生产部署后 /api/organize 为同源接口，仅向选定的三个已知服务商转发本次 API Key，不记录密钥。
